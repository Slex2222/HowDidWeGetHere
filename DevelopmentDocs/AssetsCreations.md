How to create Assets.


###########################################
###          Selecting Pallete          ###
###########################################

1. Open Libresprite 
2. Click on Options/Three horizontal bars
3. Click on Load Pallete
4. Go to this project in your file manager
5. Open the Folder ColorPalletes
6. Select the Main Pallete

###########################################
###             Asset Rules             ###
###########################################

Brush Size = 4
Brush Shape = Circular

Characters Outline Color = Black
Environment Outline Color = Darker shade of the color next to it

###########################################
###             Asset Sizes             ###
###########################################

Character Size = 64 x 64 Pixels
